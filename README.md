# Aplicaciones-de-Data-TF


**Objetivo del trabajo**

Predecir los sentimientos contenidos en las reseñas de diversos productos de Amazon con diversos modelos de clasificación entrenados para analizar sentimientos.

**Participantes**

* Alessandro Elías Hesse Pulache

**Descripción del dataset**

El dataset Amazon Sales Dataset contiene detalles sobre diversos productos de la plataforma Amazon, incluyendo precios, categoría, y rating y contenido de las reseñas sobre el producto.
